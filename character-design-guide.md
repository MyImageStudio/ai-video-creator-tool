# 👤 Character Design Guide
> สร้าง character descriptions สำหรับ Cast Mode (Dreamina) และ Character Reference (Kling)

---

## 📝 Character Description Formula

```
[Age] + [Ethnicity] + [Gender] + [Physical features] + 
[Clothing] + [Expression/Mood] + [Distinctive features]
```

---

## 🎭 Template — กรอกแล้วใช้ได้เลย

```
Character description for AI video Cast Mode:

Age: [e.g. 35 years old]
Ethnicity: [e.g. Thai / Southeast Asian]
Gender: [Male / Female]
Hair: [color, length, style]
Eyes: [color, shape]
Skin tone: [fair / medium / dark]
Build: [slim / athletic / average]
Clothing: [describe outfit in detail]
Expression: [serious / happy / mysterious / emotional]
Distinctive features: [glasses / tattoos / scar / etc.]
Overall mood/vibe: [describe the character's energy]
```

## 🎬 Cast Mode Tips (Dreamina)

1. **Upload clear face photo** — straight on, good lighting, neutral expression
2. **Use character description** in the video prompt
3. **Add "maintaining facial features"** to keep face consistent
4. **Combine with scene prompt:**

```
[Character description], [action], [location], [lighting], 
maintaining facial features and likeness, cinematic, photorealistic
```

### ตัวอย่าง Combined Prompt:
```
Thai man in his 40s with glasses, dark jacket, walking slowly 
through neon-lit street at night, rain, maintaining facial features,
cinematic wide shot, anamorphic lens, moody atmosphere
```
