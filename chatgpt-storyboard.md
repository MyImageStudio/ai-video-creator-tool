# 📋 ChatGPT Storyboard Templates
> Copy these prompts into ChatGPT (Free) to generate your storyboard instantly.

---

## 🎬 Template 1 — TikTok/Reels (12 seconds)

```
I want to create a 12-second cinematic AI video for TikTok.

Concept: [YOUR CONCEPT HERE]
Style: [cinematic / dramatic / mysterious / upbeat]
Main character: [describe briefly]
Location: [where does it take place]
Mood: [dark / bright / emotional / epic]

Please create a shot-by-shot storyboard with exactly 4 shots:
- Shot number
- Duration (total = 12s)
- Shot type (wide / medium / close-up)
- Camera movement
- Lighting
- What happens
- AI video prompt (optimized for Seedance 2.0 or Kling)

Format as a table.
```

## 🎬 Template 3 — Cinematic Short Film Style

```
I want to create a cinematic 15-second AI video in movie style.

Story: [YOUR STORY IN 1-2 SENTENCES]
Inspired by: [movie/director style — e.g. "Christopher Nolan style"]
Color grade: [dark & moody / warm golden / cold blue / etc.]
Main subject: [person / landscape / object]

Create a professional storyboard with:
- 4 shots maximum
- Each shot: type, movement, lighting, lens (e.g. 35mm, anamorphic)
- Detailed AI prompt for each shot
- Overall color grade instruction
- Sound design suggestion

Make the prompts work best with Seedance 2.0 and Kling AI.
```
